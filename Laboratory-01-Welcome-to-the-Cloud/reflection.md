# Reflection

## Mission 1: Welcome to the Cloud

This laboratory activity helped me understand the importance of Linux, cloud environments, and version control in cloud computing. At the beginning of the activity, I learned how to access a cloud-based Linux environment using KillerCoda. This allowed me to practice working with Linux without needing to install a complete Linux operating system on my computer.

One of the important parts of the activity was creating and logging into a new Linux user account. I also practiced commands such as `whoami`, `pwd`, and `hostname` to identify my current user, working directory, and system hostname. These commands helped me become more familiar with the Linux terminal.

I also learned how to gather basic system information, including the Linux distribution, kernel version, CPU information, memory, and available disk space. Creating folders and files using Linux commands helped me understand how to organize information in a Linux environment.

Another important lesson was learning how to document my work using Markdown and organize my laboratory files in GitHub. Creating a Cloud Computing Portfolio will allow me to keep my laboratory activities, screenshots, documentation, and reflections organized throughout the semester.

Overall, this activity improved my confidence in using Linux and introduced me to practical cloud computing skills. I learned that proper organization, documentation, and version control are important skills for anyone working in cloud infrastructure and information technology.
