# Reflection

## My Reflection on the Multi-Cloud Explorer Activity

This activity helped me understand the differences and similarities between AWS, Microsoft Azure, and Google Cloud Platform (GCP). The cloud platform that impressed me the most was **Amazon Web Services (AWS)** because it provides a very wide range of services for computing, storage, networking, databases, security, and application development. I also learned that AWS can support organizations from small startups to large enterprises.

AWS, Azure, and GCP have many similarities because all three provide important cloud services such as virtual machines, object storage, networking, identity management, databases, and Kubernetes. However, each provider has different strengths. Azure is especially useful for organizations that already use Microsoft technologies, while GCP is particularly strong for data analytics, artificial intelligence, machine learning, and Kubernetes-based applications.

I learned that business requirements are very important when selecting a cloud platform. An organization should consider its existing technology, budget, security requirements, application needs, scalability, location of users, and technical expertise. For example, a university using Windows Server and Microsoft 365 may benefit from Azure, while an AI research company may benefit from GCP.

Acting as a Cloud Solutions Consultant helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. The recommendation should be based on the specific needs and goals of the client. I learned to compare services and match cloud solutions with different business scenarios.

My GitHub Cloud Computing Portfolio has also improved because I now have organized research, comparisons, client recommendations, cloud service mappings, and practical Linux environment documentation. Using Markdown and GitHub helped me organize my work and track the progress of my laboratory activities. Overall, this activity increased my understanding of multi-cloud computing and how cloud technologies can be applied to real-world organizations.
