# AWS Research

## Amazon Web Services (AWS)

### 1. Brief Overview

Amazon Web Services (AWS) is a major cloud computing platform provided by Amazon. 
### 2. Global Infrastructure

AWS operates a global cloud infrastructure organized into Regions and Availability Zones. 

### 3. AWS Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. 

### 4. Four Core AWS Services

#### Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual computing capacity in the AWS Cloud. 

#### Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data. 

#### Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows organizations to create and manage virtual networks in AWS. 
#### AWS IAM

AWS Identity and Access Management (IAM) helps organizations securely control access to AWS resources.
### 5. Three Advantages of AWS

#### 1. Broad Range of Cloud Services

AWS provides a large collection of cloud services that organizations can use for computing, storage, networking, security, databases, analytics, artificial intelligence, and other workloads. AWS describes its platform as providing a broad and deep set of cloud and AI capabilities.

#### 2. Global Infrastructure

AWS provides a global infrastructure that allows organizations to deploy applications and workloads in different geographic locations. This can help organizations serve customers in different regions and design systems for availability and performance.

#### 3. Security and Access Management

AWS provides security services and access-control capabilities such as IAM. IAM supports authentication, authorization, granular permissions, and security features such as multi-factor authentication.

### 6. Typical Enterprise Use Cases

AWS can be used by enterprises for many different purposes, including:

* Hosting websites and web applications
* Running enterprise applications and virtual servers
* Storing and backing up business data
* Building scalable mobile and web applications
* Creating data analytics solutions
* Developing Artificial Intelligence and Machine Learning applications
* Building and managing distributed cloud infrastructure
* Supporting disaster recovery and business continuity

AWS serves customers ranging from startups to large enterprises, government organizations, and nonprofit organizations.
